# CP101 Lab 10 — GitHub Pages & StoryMaps

Welcome to my **CP101 Lab 10** GitHub Pages demonstration. This page shows how to publish project materials and an interactive HTML map for an ArcGIS StoryMap.

## Research Question

**How does walking distance from the nearest BART station relate to rental housing prices within 800 meters of BART stations in the Bay Area?**

This is a publishing prototype for our planned research, **not** a completed analysis of rental prices. The distance circles in the sample map use straight-line distance, not network-based walking distance.

## Planned research workflow

1. Clean rental and station datasets and document missingness.
2. Calculate walking-network distances to BART stations.
3. Explore relationships between rental prices and station access.
4. Publish analysis maps and supporting context with ArcGIS StoryMaps.
